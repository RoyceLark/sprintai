# Salon Dashboard

A reusable, responsive admin dashboard template for a salon business, built with a consistent design system and reusable UI components.

## Features

- Design system: shared color, spacing and typography tokens (`src/styles/tokens.css`).
- Reusable components: `Layout`, `Sidebar`, `StatCard`, `Button`, `DataTable`.
- Dashboard sections: Overview, Appointments, Staff, Services, Clients - all backed by mock data.
- Responsive layout: sidebar collapses into a mobile menu below the `768px` breakpoint.

## Install

```bash
npm install
```

## Run (development)

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```
